## ◈ THE IDEA

Most portfolios answer:

> **"What has this person done?"**

This one asks:

> **"What does it feel like to explore how this person thinks?"**

The entire website is designed as a **living data universe**.

The visitor enters the system, moves through interconnected environments, discovers projects and achievements, and eventually watches everything converge into one final point.
